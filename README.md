# Tiramisu 3D

A cozy little 3D house game. Decorate a modern two-storey home, look after your pets, and spin the camera all the way around to see every corner.

It is a 3D remake of the Tiramisu App, a 2D isometric browser game, rebuilt as a PC game with high end, film-like graphics (Unity 6 HDRP on DirectX 12), high poly models made in Blender, real PBR textures and realistic physics.

Made by Amir Ariffin (Zetazuni) for Athirah ♥

## Status

Early days: the house, the 360 degree camera, the lighting and the first furniture are in. See `docs/devlog.md` for progress.

## Opening the project

1. Install Unity 6000.6.3f1 through Unity Hub.
2. Clone with Git LFS installed (`git lfs install` once), so models and textures download properly.
3. Open the folder in Unity Hub. A DirectX 12 capable GPU is needed.

Textures are CC0 from Poly Haven, see `Assets/Art/Textures/CREDITS.txt`.

Notes for contributors (and for Claude) start at `CLAUDE.md`.
