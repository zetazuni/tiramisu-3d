# Tiramisu 3D

A cozy little 3D house game. Decorate a modern two-storey home, look after your pets, and spin the camera all the way around to see every corner.

It is a 3D remake of the Tiramisu App, a 2D isometric browser game. Models are made in Blender and the game is built in Unity 6.

Made by Amir Ariffin (Zetazuni) for Athirah ♥

## Status

Early setup. Nothing playable yet. See `docs/devlog.md` for progress.

## Opening the project

1. Install Unity 6000.6.3f1 through Unity Hub.
2. Clone with Git LFS installed (`git lfs install` once), so models and textures download properly.
3. Open the folder in Unity Hub.

Notes for contributors (and for Claude) start at `CLAUDE.md`.
